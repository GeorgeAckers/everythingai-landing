# EverythingAI — Lead Reactivation Landing Page

Single-page landing site for the Lead Reactivation AI Assistant demo.
Served by GitHub Pages straight from `index.html` on the `main` branch.

Everything the page needs is in that one file: the logo and favicon are
embedded as data URIs, and the only external calls are Google Fonts and
the Calendly embed script. There are no build steps and no asset folder,
so editing `index.html` and pushing is the whole deploy process.
